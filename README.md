# Development Kit for JINS MEME ES_R (JINS MEME Academic Pack)

> [!NOTE]
> **Measuring with macOS, Windows, or iOS**
>
> When measuring with macOS, Windows, or iOS, a very small noise originating from the Bluetooth communication cycle appears in the gyroscope (angular velocity) and EOG data. It appears at around 33 Hz and nearby frequencies when measuring at 100 Hz, and at around 17 Hz and nearby frequencies when measuring at 50 Hz. Accelerometer data is not affected. In addition, on macOS and iOS, some data may be missing.
>
> For analyses that handle fine signals at rest, such as frequency analysis, we recommend measuring with Android.

This repository provides you the Development Kit including sample codes for JINS MEME ES_R, previously called JINS MEME Academic Pack.

We've prepared the ES_R Development Kit for four environments. Please go to the links for more details.

* [ES_R Development Kit for Android](https://github.com/jins-meme/ES_R-Development-Kit/tree/master/android)
* [ES_R Development Kit for Mac](https://github.com/jins-meme/ES_R-Development-Kit/tree/master/Mac)
* [ES_R Development Kit for Windows](https://github.com/jins-meme/ES_R-Development-Kit/tree/master/windows)
* [ES_R Development Kit for iOS / iPadOS](https://github.com/jins-meme/ES_R-Development-Kit/tree/master/iOS/ES_R_DevKit_iOS)

The Mac / Windows / Android / iOS full-featured apps share one graph page (a web page shown in a WebView); see [webview](https://github.com/jins-meme/ES_R-Development-Kit/tree/master/webview).
