# Development Kit for JINS MEME ES_R (JINS MEME Academic Pack)

This repository provides you the Development Kit including sample codes for JINS MEME ES_R, previously called JINS MEME Academic Pack.

We've prepared the ES_R Development Kit for three environments. Please go to the links for more details.

* [ES_R Development Kit for Android](https://github.com/jins-meme/ES_R-Development-Kit/tree/master/android)
* [ES_R Development Kit for Mac](https://github.com/jins-meme/ES_R-Development-Kit/tree/master/Mac)
* [ES_R Development Kit for Windows](https://github.com/jins-meme/ES_R-Development-Kit/tree/master/windows)

The Mac / Windows / Android full-featured apps share one graph page (a web page shown in a WebView); see [webview](https://github.com/jins-meme/ES_R-Development-Kit/tree/master/webview).
